Notis Privasi (PDPA 2010)

Sistem ini menyimpan emel, nama, role akaun dan rekod log masuk anda untuk kawalan akses dan keselamatan sahaja. Rekod log masuk disimpan selama 180 hari, sesi log masuk tamat selepas 12 jam. Tiada data sensitif (No. IC, kesihatan) dikumpul. Untuk semak, betulkan atau padam data akaun, hubungi admin sistem.

Lupa password? Minta admin reset password anda.

Tukar Password

Anda mesti tukar password sementara sebelum boleh guna sistem.

Min 10 aksara, ada huruf dan nombor, tak boleh mengandungi emel.
